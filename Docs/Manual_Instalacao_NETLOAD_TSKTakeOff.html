TSK TakeOff

Manual de instalação e início rápido

AutoCAD 2021–2026
O TSK TakeOff é um plugin para medir elementos de obra diretamente no AutoCAD, organizar as medições no desenho e gerar a folha de medição no Excel.

1. Requisitos

  • Windows 10 ou Windows 11;
  • AutoCAD 2021 a 2026, versão 64 bits;
  • Microsoft Excel instalado apenas se for utilizar o recurso Excel ao Vivo;
  • arquivo DWG com as unidades do projeto configuradas corretamente.

A exportação da folha para .xlsx pode ser realizada sem o Excel aberto.

2. Instalação recomendada

1Feche o AutoCAD

Feche todas as janelas do AutoCAD antes de iniciar a instalação.

2Extraia o pacote

Extraia todo o conteúdo do arquivo ZIP para uma pasta local, por exemplo:

C:\TSKTakeOff

Importante: não mova apenas a DLL. Todas as pastas e arquivos do pacote precisam permanecer juntos.

3Execute a instalação

Se o pacote possuir o arquivo instalar.bat, execute-o com o botão direito e escolha Executar. O bundle será instalado no perfil do usuário, sem necessidade de direitos de administrador.

Como alternativa, copie a pasta TSKTakeOff.bundle inteira para:

%APPDATA%\Autodesk\ApplicationPlugins\

4Abra o AutoCAD

Abra o AutoCAD e um desenho DWG. O separador TSK TakeOff deverá aparecer automaticamente na ribbon.

Confirmação: também é possível digitar TSKPAINEL na linha de comandos para abrir o painel de medições.

3. Instalação manual com NETLOAD

Utilize este procedimento somente quando tiver recebido uma DLL avulsa em vez do bundle instalável.

  1. Extraia o pacote para uma pasta local.
  2. Nas propriedades do arquivo, marque Desbloquear, caso essa opção apareça.
  3. Abra o AutoCAD e digite NETLOAD.
  4. Selecione a DLL compatível com a versão do AutoCAD.
  5. Se o AutoCAD perguntar se deseja carregar o arquivo, confirme com Carregar sempre, quando essa opção estiver disponível.

Não misture as builds: uma DLL destinada ao AutoCAD 2021–2024 não deve ser carregada no AutoCAD 2025–2026, nem o contrário.

4. Primeiro uso

  1. Abra o Painel de Medições.
  2. Informe o serviço ou material, piso, altura e espessura.
  3. Escolha a regra de desconto dos vãos, quando aplicável.
  4. Se possuir um mapa de quantidades, importe-o com TSKMQT e escolha o artigo correspondente.
  5. Escolha a ferramenta de medição e selecione ou desenhe a geometria no AutoCAD.
  6. Confira os vãos detectados e os valores apresentados na grade.
  7. Use Excel ao Vivo para acompanhar a folha ou Exportar XLSX para gerar o arquivo final.

6. Licença

A instalação inclui um período de avaliação conforme as condições comerciais da TSK Digital. Para consultar ou ativar uma licença, use o comando TSKLICENCA ou o botão Licença na ribbon.

A licença fica associada à instalação. Em caso de troca de computador, entre em contato com o suporte para solicitar uma nova ativação.

Mesmo quando a licença precisa ser renovada, o usuário continua podendo consultar as medições existentes e exportar o trabalho.

7. Solução de problemas

O separador TSK TakeOff não aparece

  1. Feche e abra novamente o AutoCAD.
  2. Confirme se a pasta TSKTakeOff.bundle foi copiada inteira.
  3. Digite TSKPAINEL para verificar se o plugin foi carregado.
  4. Se o Windows bloqueou os arquivos, abra as propriedades da DLL, marque Desbloquear e tente novamente.
  5. Se necessário, adicione a pasta à lista de locais confiáveis em Options → Files → Trusted Locations.

As medições não aparecem

Digite TSKONDE para verificar onde as medições estão gravadas, se a layer está desligada e em qual espaço do desenho os elementos foram criados.

O Excel não atualiza

Confirme que o Excel está instalado, finalize qualquer edição de célula e carregue em Atualizar. Se o Excel tiver sido fechado, ligue novamente o recurso Excel ao Vivo.

O modelo do Excel abriu em Vista Protegida

Abra o modelo diretamente no Excel e clique em Habilitar Edição. Depois, volte ao AutoCAD e tente novamente.
